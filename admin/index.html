Masuk ke Admin

Masukkan GitHub Personal Access Token kamu. Ini disimpan cuma di browser kamu sendiri, gak dikirim ke mana-mana selain langsung ke GitHub.

  1. Buka github.com/settings/tokens (harus login dulu)
  2. Tap Generate new token (pilih "Fine-grained token")
  3. Kasih nama bebas, contoh "admin-preorder"
  4. Expiration: pilih durasi yang kamu mau (misal 90 hari, nanti bikin baru lagi kalau habis)
  5. Repository access → pilih "Only select repositories" → pilih repo postatusaugust ini aja
  6. Permissions → cari "Contents" → set jadi Read and write
  7. Generate token, copy hasilnya (cuma muncul sekali!), paste di sini

⚠️ Jangan share token ini ke siapapun. Siapapun yang pegang token ini bisa ubah isi repo kamu.
